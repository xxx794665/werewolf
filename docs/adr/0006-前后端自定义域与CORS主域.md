# ADR-0006：前后端走用户配置的自定义域

日期：2026-10-03。状态：已采纳。

## 背景与决策

第一版默认后端地址为 workers.dev（`werewolf-room.249939260.workers.dev`），本机实测命中地区性 DNS 污染不可达（母本 situation_puzzle 同款经验）。2026-10-03 用户在 Cloudflare 侧完成两项配置：

1. 前端：`werewolf.xxx794665.party` 反代 GitHub Pages（github.io 地址 301 过去）；
2. 后端：`werewolf-room.xxx794665.party` 绑定 Worker（本机直连可达）。

据此决策：

- `js/net.js` 默认后端地址改为 `https://werewolf-room.xxx794665.party`；
- Worker `ALLOWED_ORIGINS` 增补 `https://werewolf.xxx794665.party` 并置于白名单首位（无 Origin 的请求回显首项）；
- workers.dev 地址保留为备用（仍有效），`localStorage.ww_api_base` 仍可覆盖接口地址。

## 后果

- 默认链路不再依赖 workers.dev 的可达性，DNS 污染风险解除（README 已知限制同步改写）。
- CORS 白名单改动必须重新 `npx wrangler deploy` 才生效（本次实测踩过：只改 toml 不部署，新域不回显 CORS 头）。
- 后续换域名要动三处：`js/net.js` 默认值、`worker/wrangler.toml` 白名单、`tools/check_site.cjs` 的白名单断言（tests 里两处 env 同步），并在 `docs/TASKS.md` 记录。
