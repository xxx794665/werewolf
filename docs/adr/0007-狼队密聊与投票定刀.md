# ADR-0007：狼队密聊 + 投票定刀，AI 人格池与反间策略层

日期：2026-10-03。状态：已采纳（features.md §4.1.1 / §8.3 已同步）。
修订：2026-10-04——密聊「天亮即清空」条款作废：`night.wolfChat` 改为全程日志 `wolfChatLog`（带夜号跨夜保留，仅存活狼座可见），白天可回看历史（UI 只读卡 + 狼 AI 白天提示词注入），见 features.md §4.1.1 修订记录。

## 背景与决策

第一版夜晚狼阶段是「狼队长独裁」：只有队长提交刀口，其余狼人完全沦为旁观 NPC，没有参与感。用户点名三项改进，决策如下：

1. **狼队密聊**：夜晚 wolf 子阶段开放只有存活狼人可见的聊天频道（`night.wolfChat`）——每人每晚至多 5 条、每条 ≤60 字、天亮即清空、不产生公开事件。频道内容走 roleCard 白名单进 AI 上下文（上下文铁律不破，狼聊本就是狼座合法私有信息）。
2. **投票定刀**：废除队长独裁，改为每个存活狼人一票（不可改票），全部投完的瞬间按最高票定刀；平票由狼队长一锤定音（队长的票在平票集合中则从其票，否则取最小座位号）。狼队长从「独裁者」变为「平票裁定者」。待行动座位 = 第一个未投票的存活狼，150s 超时与 AI 驱动按此逐狼推进。允许投队友 / 自己（自刀、弃车是合法战术，与 §8.4 回退同口径）。
3. **AI 人格池**：8 款言行风格人格（盘逻辑 / 直率冲锋 / 乐子人 / 老实人 / 戏精 / 暴民 / 老油条 / 寡言刀客）按座位号确定性分配。人格只含风格与心态、不含身份信息。狼人策略层明确反间战术：狼咬狼（投队友换信任）、假跳狼、报假信息钓反应、深水到底。
4. **狼阶段 AI 输出改两行**：第一行密聊发言（「过」= 无话）、第二行刀口座位号；`parseWolfReply` 解析，缺票走确定性回退随机投、密聊保留。`drive_ai` 狼阶段一次调用两段提交（先密聊后投票）。
5. **AI 设置连接测试**：设置页「测试连接」按钮用输入框当前值（未保存也能测）发一条最小请求（max_tokens 16、单次不重试、15s 超时），走与游戏相同的 `/api/ai-proxy` 链路，回显延迟与上游回复或可读失败原因。

## 后果

- 狼阶段 AI 调用从每晚 1 次变为每狼 1 次（最多 3 次/夜），单局 AI 调用总量上浮（README 已知限制同步）。
- 快照安全边界新增一处纪律：`wolfChat / wolfVotes / captain` 字段只出现在存活狼座快照与狼阶段 roleCard，`acceptance` 测试有字段白名单与「非狼不得见密聊」探针。
- 部署过渡：旧持久化房间的 `night` 无新字段，内核在 wolf 动作入口就地补齐（`wolfChat=[]` / `wolfVotes={}`），不砖房。
- 换板子 / 调密聊限额只动 `shared/game.js` 顶部常量（`WOLF_CHAT_MAX` / `WOLF_CHAT_TURNS`）。
